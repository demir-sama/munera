# Munera demo audio – credits & licenses

## Voice
- Engine: Microsoft Edge neural TTS via the `edge-tts` Python package (free, no account/key), voice **en-US-AndrewMultilingualNeural**, rate -6 %.
- Post: leading/trailing silence trimmed, 70 Hz high-pass, de-esser, light compression, per-line loudness match, limiter, whole track normalized to -16 LUFS (stereo-equivalent).
- Note: Microsoft's Edge TTS service is an online service intended for the Edge browser's Read Aloud; there is no formal license grant for redistribution. If you need a guaranteed-clean license for commercial use, regenerate the lines with Piper (MIT code, voice-model licenses vary) or a paid TTS. Fallback Piper v1 audio is still in `munera-demo.mp4`.
